# Ficheiros de exemplo para sorteios

Esta pasta contem ficheiros Excel para testar cada formato de sorteio no DForce.

## Ficheiros

- `Champions_36_Equipas_Exemplo.xlsx`: formato Champions.
- `Grupos_24_Equipas_Exemplo.xlsx`: fase de grupos.
- `Liga_16_Equipas_Exemplo.xlsx`: liga todos contra todos.
- `Qualificacao_20_Equipas_Exemplo.xlsx`: qualificacao com grupos.
- `Eliminatorias_32_Equipas_Exemplo.xlsx`: eliminatorias diretas.
- `Taca_16_Equipas_Exemplo.xlsx`: taca em eliminatorias diretas.

## Como testar

Carrega um dos ficheiros no DForce e confirma que o formato de sorteio e atualizado automaticamente quando o nome do ficheiro identifica o formato.

Se escolheres manualmente outro formato depois de carregar o ficheiro, a app deve mostrar o aviso de incompatibilidade antes de prosseguir.
